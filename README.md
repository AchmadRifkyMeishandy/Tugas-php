# Latihan Pemrograman PHP

Kumpulan tugas dan percobaan untuk mempelajari dasar PHP, pengolahan input, perhitungan, dan logika program.

## Topik Latihan

- Variabel dan operasi aritmetika.
- Percabangan `if` dan `switch`.
- Form input serta pengolahan data.
- Perhitungan nilai akhir siswa.
- Kalkulator sederhana.
- Perhitungan luas segitiga dan latihan logika lainnya.

## Teknologi

- PHP
- XAMPP atau server lokal yang mendukung PHP
- Web browser
- Editor kode seperti Visual Studio Code

## Menjalankan

1. Jalankan Apache melalui XAMPP atau server PHP lokal.
2. Letakkan folder repository di document root, misalnya `htdocs`.
3. Buka file yang ingin dipelajari melalui browser, misalnya `http://localhost/Tugas-php/kalkulator.php`.

Repository ini adalah arsip pembelajaran awal. Penamaan file, struktur folder, validasi input, dan pemisahan kode dapat dirapikan secara bertahap.
